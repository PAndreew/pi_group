# Beezy

Beezy is a self-hosted chat workspace for people and their [pi coding agent](https://github.com/earendil-works/pi). Chat together, let agents work on files and run tools, and follow along in a shared browser—even after you close your own tab. [Try the interactive demo](https://pandreew.github.io/pi_group/) to explore fictional accounts, sessions, tool calls, browser previews, and resource usage without signing in or connecting a model. See the [getting-started guide](docs/getting-started.md) to run Beezy on your computer or Raspberry Pi.
